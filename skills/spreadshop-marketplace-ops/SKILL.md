# Purpose
Use when deciding whether Spreadshop should be a primary storefront, supplemental merch channel, or fulfillment bridge through Spreadconnect.

# Platform facts
- Spreadshop promotes a free-to-use hosted storefront with no upfront fees and no inventory requirement.
- It supports 300+ products and lets the seller set product pricing above the base price.
- Spreadconnect is the connected fulfillment option for external ecommerce channels.

# Evaluation framework
1. Determine the role: branded storefront, creator merch outpost, or test channel.
2. Compare product range, print quality expectations, shipping regions, storefront customization, and margin control.
3. Decide whether the platform is for always-on evergreen merch or audience-specific drops.
4. Define how it complements Shopify instead of fragmenting the brand.
