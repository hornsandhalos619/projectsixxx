# Purpose
Use for building paid acquisition experiments and creative testing systems.

# Workflow
1. Define objective and budget.
2. Generate multiple ad angles.
3. Separate creative hypotheses from audience hypotheses.
4. Build a testing matrix with pass/fail rules.
5. Recommend iteration based on data.

# Output format
## Campaign Objective
## Creative Angles
## Test Matrix
## Budget Split
## KPI Targets
## Scale / Kill Rules
