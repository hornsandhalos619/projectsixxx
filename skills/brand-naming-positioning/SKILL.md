# Purpose
Use when naming, renaming, positioning, or clarifying the narrative identity of the brand.

# Inputs
- concept
- audience
- tone
- taboo words
- domain preferences
- trademark caution level

# Naming workflow
1. Generate broad options across several styles: literal, poetic, luxury, streetwear, symbolic, editorial.
2. Remove generic, hard-to-pronounce, or weakly ownable names.
3. Score remaining names on memorability, distinctiveness, symbolism fit, pronounceability, visual potential, merchability.
4. Produce a shortlist with rationale and risks.

# Positioning workflow
1. Define audience tension.
2. Define category frame.
3. Write positioning statement.
4. Write 3 to 5 USP options.
5. Write voice principles and anti-voice rules.

# Output format
## Name Territories
## Candidate Names
## Scored Shortlist
## Positioning Statement
## USP Options
## Voice Principles
## Risks

# Quality bar
- Avoid empty edgy names.
- Avoid names that sound like random generator outputs.
- Prefer names that can scale from apparel to art objects to collaborations.
