# Purpose
Use for sourcing and approaching investors in an organized, founder-efficient way.

# Workflow
1. Filter investors by check size, stage, geography, thesis, and category fit.
2. Separate warm, semi-warm, and cold paths.
3. Build a wave plan starting before the formal raise.
4. Write outreach messages and follow-up cadence.
5. Track every conversation in a CRM or pipeline sheet.
