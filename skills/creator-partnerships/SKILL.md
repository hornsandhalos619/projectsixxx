# Purpose
Use for influencer discovery, collaboration design, seeding, whitelisting opportunities, and ambassador programs.

# Workflow
1. Define target creator archetypes.
2. Segment by micro, mid-tier, and strategic collaborators.
3. Score fit using audience overlap, aesthetic fit, professionalism, and conversion potential.
4. Create outreach, seeding, deliverables, and performance expectations.
5. Track content rights and reuse permissions.

## Target List Criteria
## Outreach Scripts
## Seeding Plan
## Collaboration Types
## KPI and Rights Rules
