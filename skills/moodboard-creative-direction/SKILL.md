# Purpose
Use when the user needs visual direction before design production, photography, packaging, or campaign creative.

# Inputs
- positioning
- audience
- product categories
- emotional tone
- reference brands or artists

# Workflow
1. Define 3 distinct art directions.
2. For each route, specify palette, lighting, textures, typography direction, composition rules, styling cues, packaging cues, and campaign mood.
3. Describe what to avoid so the route stays coherent.
4. Connect each route back to audience appeal and conversion use.

# Output format
## Route 1
- Name
- Emotional promise
- Palette
- Materials and textures
- Type direction
- Image direction
- Packaging direction
- Best use cases
- Avoid

## Route 2
...

## Route 3
...

# Quality bar
- Be concrete enough that a designer or image model can act on it immediately.
- Do not use vague terms like cool, modern, or premium without visual translation.
- Each route must feel genuinely different.
