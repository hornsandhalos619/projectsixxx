# Purpose
Use for budgeting, unit economics, scenario planning, and board-level KPI decisions.

# Workflow
1. Build low, medium, and high budget scenarios.
2. Define revenue assumptions by channel.
3. Model margin by SKU and blended margin by channel.
4. Create CAC tolerance and break-even thresholds.
5. Define dashboard metrics and target ranges.
