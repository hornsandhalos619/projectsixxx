# Purpose
Use whenever pricing, margin, cost of goods, shipping, or CAC-sensitive economics need to be modeled.

# Workflow
1. Identify all unit costs.
2. Add packaging, shipping, taxes, platform fees, and payment fees.
3. Set target gross margin and contribution margin.
4. Test price bands against audience willingness and brand positioning.
5. Compute break-even and sensitivity ranges.
