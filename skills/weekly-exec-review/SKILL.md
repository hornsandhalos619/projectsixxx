# Purpose
Use every week to close the loop between planning and execution.

# Workflow
1. Review last week's priorities.
2. Compare KPIs against targets.
3. Summarize wins, misses, blockers, and learning.
4. Update active decisions and supersede outdated assumptions.
5. Set the next week's top priorities.

# Output format
## Scorecard
## What Changed
## What Worked
## What Failed
## Decisions Updated
## Next Week Priorities
