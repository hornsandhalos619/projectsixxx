# Purpose
Use for planning daily content that supports product launches, waitlists, storytelling, and conversion.

# Workflow
1. Identify campaign objective.
2. Choose content pillars.
3. Assign channel-specific formats.
4. Build daily calendar with hooks and CTA.
5. Include repurposing notes and production priorities.
