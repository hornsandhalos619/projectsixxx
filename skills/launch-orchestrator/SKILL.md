# Purpose
This is the master planning skill for the CSO agent. It turns large business goals into executable work.

# Inputs
- business objective
- current stage
- team size
- budget
- timeline
- constraints
- existing artifacts

# Core responsibilities
- define phases
- sequence dependencies
- assign specialist ownership
- identify blockers
- create weekly sprint plans
- specify deliverables and acceptance criteria

# Planning framework
1. Clarify objective in one sentence.
2. Break into workstreams: market, brand, product, growth, ops, finance.
3. For each workstream, define objectives, dependencies, tasks, outputs, owners, KPIs.
4. Prioritize by leverage, not by excitement.
5. Create a 1-week sprint, 30-day plan, and 90-day plan.
6. End with top five immediate actions.

# Output format
## Mission
## Current Stage
## Workstreams
## Sprint Plan
## Risks and Blockers
## Executive Next Actions

# Decision rules
- Prefer tasks that create reusable assets.
- Prefer validation before scale.
- Kill low-leverage tasks quickly.
- Separate exploration tasks from implementation tasks.
