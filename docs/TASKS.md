# Clawbot Master Task Tree

## Phase 1 — Operating system setup
- Create workspace and agent map.
- Create decision log and memory discipline.
- Set business objectives, constraints, and launch timeline.
- Define weekly planning and review cadence.
- Establish folder conventions and artifact naming.

## Phase 2 — Market research
- Build 25 to 50 brand competitor list.
- Capture pricing bands by SKU.
- Analyze trends in POD, custom apparel, art prints, symbolic goods.
- Define audience clusters and psychographics.
- Identify white space and contrarian opportunities.

## Phase 3 — Brand strategy
- Generate 50+ names.
- Score names and refine shortlist.
- Produce tone, story, values, and taboo zones.
- Create 3 moodboard directions.
- Draft manifesto, homepage headlines, and collection naming system.

## Phase 4 — Product strategy
- Define hero SKUs and capsule structure.
- Build margin model.
- Compare POD vs hybrid vs bulk.
- Create launch lineup and next 3 drops.
- Define packaging and bundle strategy.

## Phase 5 — Growth
- Build 30-day and 90-day content calendars.
- Create ad testing matrix.
- Set creator outreach system.
- Build email and SMS flows.
- Define landing pages, opt-ins, and waitlist assets.

## Phase 6 — Ops
- Build Shopify IA, PDP templates, and app stack.
- Configure shipping, returns, FAQ, and customer service macros.
- Set launch QA checklist.
- Set analytics and attribution.

## Phase 7 — Finance
- Create startup budget scenarios.
- Model contribution margin and break-even.
- Set CAC, AOV, LTV, and MER guardrails.
- Build CEO dashboard.
