
# Founder Security and Legal Control

## Technical controls
- Run OpenClaw gateway on loopback or private network only unless remote access is absolutely necessary.
- Use environment variables for API keys and tokens.
- Restrict shell/network tool permissions by allowlist.
- Create a dedicated exec-guard agent for sensitive workflows.
- Use MFA on domain, email, Shopify, bank, registrar, cloud, and password manager accounts.
- Maintain separate founder email and admin email patterns.

## Password and secret model
- Use a password manager.
- Generate unique long random passwords for every critical account.
- Use hardware-backed MFA where possible.
- Never put secrets in markdown, git, chats, or screenshots.

## Legal controls
- Form LLC or corporation based on counsel advice; keep accounts separate.
- LLC filing is not trademark protection; file trademark strategy separately.
- Use IP assignment agreements with employees and contractors.
- Keep founder control over domain, trademark filings, store ownership, and payment rails.
- Use operating agreement or bylaws that define authority, approvals, equity, vesting, and transfer restrictions.
