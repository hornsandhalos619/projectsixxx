
# Executive Instruction Manual

## Your role
You are not using Clawbot as a do-everything assistant. You are using it as a business operating system.

## Daily executive routine
1. Start with Aurelius (cso) for a 5-minute control review.
2. Ask for: current priorities, blockers, deadlines, and decisions needed today.
3. Approve or reject no more than 3 major priorities.
4. Delegate execution to specialists.
5. End day with a decision-memory update.

## Weekly executive routine
- Monday: ask Aurelius for sprint plan.
- Tuesday: review Argus and Vesper outputs.
- Wednesday: review Forge and Harbor execution readiness.
- Thursday: review Pulse campaign readiness and Ledger financial guardrails.
- Friday: run weekly-exec-review and update decisions.

## Decision rules
- Keep Shopify as flagship.
- Treat marketplaces as channel roles, not equal homes.
- Require margin review before launch.
- Require legal review before name lock, contract signature, or fundraising material distribution.
- Require Citadel review before enabling new external integrations or remote access.

## Founder-only controls
- Founder retains registrar, DNS, payment processor, Shopify owner, primary email, password manager, and banking control.
- All admin credentials must be stored in a password manager with MFA.
- Contractor access is delegated, time-limited, and revocable.
